# The 5 P's

Run the `five-ps` skill.

Brand, person or product, and mode (empty = apply; "audit <brand>" = diagnose): $ARGUMENTS

Start with Step 0: collect the facts already on this machine, list what is missing, and ask
once if she is present. Then write the plan in the skill's eight sections and save it as
`<BRAND>_5Ps.md` in the brand's working folder. Never fill a gap with a guess.
